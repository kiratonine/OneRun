# OneRun

Хакатонный проект: консолидация мелких грузов в один сводный рейс по Мангистауской области.
Дедлайн — 20.08.2026, 16:00.

## Что где

- `frontend/` — вся зона нашей ответственности. React 19 + Vite + TS + Tailwind v4 + shadcn/ui.
- `backend/` — **не трогаем**. Пишут два других разработчика в отдельной ветке.
- `context/` — ТЗ и планы всех трёх ролей. `context/PROGRESS.md` — состояние работы по сессиям.

Ветка: `feat/frontend`.

Три вкладки (`/`, `/orders`, `/report`) плюс два служебных роута вне навигации:
`/demo` — пульт для телефона, `/health` — диагностика бэкенда против контракта.
На любой вкладке **Ctrl+Shift+X** открывает резервный пульт демо — на случай,
если на питче подведёт телефон или вайфай.

## Правила, которые нельзя нарушать

**Контракт API.** Типы в `frontend/src/api/types.ts` согласованы с бэкендом
(`context/plan-frontend.md` §4 = `context/plan-backend-1.md` §7). Менять их в одностороннем
порядке нельзя — только через договорённость.

**Координаты — `[lon, lat]`.** GeoJSON и MapLibre ждут именно этот порядок. `Settlement.lat/lon` —
отдельные поля, при сборке геометрии собираем `[lon, lat]` вручную. Перепутанный порядок
отправляет линии в Индийский океан.

**Координаты посёлков не выдумываем.** Всё в `mock-data.ts` получено из Nominatim и помечено
источником — это требование ТЗ (AC-13), его проверяют на питче.

**Константы.** Всё, что известно до рантайма, — в `src/config/constants.ts` в `UPPER_SNAKE_CASE`.
Конфиг-объекты, которые спредятся, остаются в `camelCase` даже под `as const`.

**Карта живёт вне React.** Инстанс MapLibre создаётся один раз в `useEffect` с пустыми
зависимостями, лежит в `useRef`, слои меняются императивно. Никакого ререндера карты на state.
Набор однотипных объектов = **один source и один layer**, обновляется через `setData`,
а не слой на каждую заявку.

## Команды

```bash
cd frontend
npm run dev        # дев-сервер
npm run build      # tsc -b && vite build  ← настоящий гейт качества
npm run typecheck  # tsc -b --force
npm run lint
```

`npm run build` — единственная надёжная проверка типов. Не полагайся на `tsc --noEmit`:
конфиг solution-style, и без `-b` проверка молча ничего не делает.

## Грабли, на которые уже наступили

**maplibre-gl запинен на `^5`.** В 6.4.1 URL воркера выводится из `import.meta.url`, после
бандлинга Vite не находит `maplibre-gl-worker.mjs`, `getWorkerUrl()` возвращает пустую строку —
воркер молча не создаётся, векторные тайлы не парсятся, событие `load` не наступает,
слои не добавляются. **Не обновлять до v6** без проверки карты в браузере.

**После смены версии зависимости чисти `node_modules/.vite`** и перезапускай дев-сервер,
иначе Vite отдаёт старый пре-бандл и валится на `does not provide an export named 'default'`.

**Шрифт подписей — только `Noto Sans`** (`MAP_LABEL_FONT`). Стиль OpenFreeMap Liberty отдаёт
глифы лишь для него; дефолтный стек symbol-слоя даёт 404 в консоли.

**Git Bash ломает кириллицу в argv** (перекодирует в cp1251). Для запросов с кириллицей —
Node или предварительное URL-кодирование, не `curl --data-urlencode` из bash-скрипта.

**Проверка мока из консоли браузера врёт после HMR.** `import('/src/api/client.ts')` из
DevTools/Playwright после правки исходников отдаёт **второй экземпляр модуля**: приложение к
этому моменту грузит его как `client.ts?t=<timestamp>`, а плоский путь создаёт новый — со своим
`mockStore`. Симптом: дёргаешь `api.resetDemo()`, а на экране по-прежнему шесть заявок, и
кажется, что сломался опрос. Лечится перезапуском дев-сервера перед прогоном (перезагрузки
страницы мало — `?t=` живёт в графе модулей Vite).
